Experiments and paper-facing analyses run on Ubuntu 22.04.5 LTS with an Intel Xeon Gold 6530 CPU (14 allocated cores), 117 GiB RAM, and one NVIDIA GeForce RTX 5090 GPU (driver 580.65.06; CUDA toolkit 13.0). The software environment uses Python 3.10.20, PyTorch 2.12.0+cu132, Transformers 5.8.1, scikit-learn 1.7.2, pandas 2.3.3, NumPy 2.2.5, and SciPy 1.15.3.
